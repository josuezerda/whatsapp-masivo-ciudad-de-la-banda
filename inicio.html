¿Qué hace el sistema?

Plataforma completa para gestionar comunicaciones municipales vía WhatsApp Business API de Meta.

📨
Envío Masivo
Enviá mensajes a toda la base o por segmento. Control de velocidad y monitoreo en tiempo real del progreso de entrega.
📋
Plantillas Aprobadas
6 plantillas de mensaje aprobadas por Meta para tránsito, libre deuda y comunicados generales.
👥
Base de Datos
Gestión de 11.258 contactos con búsqueda, filtrado por segmento y paginación. Importación vía CSV.
📊
Reportes
Gráficos de actividad, tasas de entrega y lectura, distribución por bases de datos y estadísticas de campañas.
🔒
Acceso Seguro
Autenticación via Supabase Auth con HTTPS cifrado. Solo personal autorizado puede acceder al sistema.
⚙️
Configuración API
Gestión segura de credenciales WhatsApp Business API (Token, Phone Number ID, WABA ID) con almacenamiento local.

Transparencia y Privacidad

Este sistema opera bajo la Ley N° 25.326 de Protección de Datos Personales de Argentina y cumple con las políticas de WhatsApp Business de Meta Platforms.
