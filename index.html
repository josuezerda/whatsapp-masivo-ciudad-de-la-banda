  1. Ingresá a developers.facebook.com → Tu App → WhatsApp → API Setup
  2. Copiá el Phone Number ID y el Temporary Access Token (o generá uno permanente)
  3. El WABA ID está en la sección "WhatsApp Business Account"
  4. El Webhook Verify Token es el string que pusiste al configurar el webhook
  5. Pegá todos los datos abajo y presioná "Probar Conexión"
